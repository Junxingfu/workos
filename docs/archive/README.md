# 前端文档

这个目录放 WorkOS 前端的全部资料：前端规范、设计系统、页面交互、Agent 执行规则，以及历史版本。

## 现行（改前端就看这两份）

| 文件 | 用途 | 什么时候看 |
|---|---|---|
| `前端规范.md` | **WorkOS 前端唯一规范（v2.0 工作界面重构规范）**：目标、设计原则、视觉系统、布局、ItemRow、Drawer、六个页面规格、反馈与状态、交互规则、工程约定、验收、实现现状 | 需要做设计决策，或想知道「为什么这么定」 |
| `前端Agent规则.md` | Agent 执行规则：硬约束 N1~N41、契约、可直接跑的验收命令 | 写代码前先读，交付前按它自检 |

两份同源。冲突时以 `前端规范.md` 为准，并顺手修正 `前端Agent规则.md`。

路径约定：文中的 `src/...` 均相对 `workos-web/`；验收命令在 `workos-web/` 目录下执行。
